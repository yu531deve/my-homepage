## 技術選定

やりたいことは「ポートフォリオ + ブログ + スクロール演出の技術デモ」の3つ。この組み合わせだと選択肢はだいたい絞られました。

- **Astro** — 静的サイトとして速く、Markdown をそのままコンテンツとして扱える。記事や作品の追加が `.md` を置くだけで完結する点が決め手
- **Tailwind CSS v4** — 色・フォント・イージングを `@theme` に集約して、デザイントークンとして一元管理できる
- **GSAP + ScrollTrigger** — スクロール量に連動して動かす(scrub)用途では実績が多く、情報も揃っている

ホスティングは Cloudflare Pages。まずは `*.pages.dev` で公開して、独自ドメインは後回しにしました。

## 骨組みを先に作る

デザインを詰める前に、全ページのルーティングだけ先に通しました。`/`・`/works`・`/works/[slug]`・`/about`・`/blog`・`/blog/[slug]`・`/contact` の7つ。中身はプレースホルダでも、リンクが繋がっている状態を早く作ると全体像が掴みやすくなります。

## デザインの方向性

ダーク基調に大胆なモーション、アクセントはエメラルド系。色は直接書かず、`--color-accent` のようなトークンとして定義しておいて、後から一括で調整できるようにしています。

## 次回

作品とブログのコンテンツモデルを定義して、一覧・詳細ページを Markdown 駆動に置き換えます。

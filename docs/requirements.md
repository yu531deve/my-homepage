# 個人ホームページ 要件定義書

作成日: 2026-08-18 / ステータス: ドラフト v0.1

## 1. 目的

- ポートフォリオとして制作物・プロジェクトを見せる
- 自己紹介・経歴・スキルを伝える
- ブログとして継続的に発信する
- スクロール演出そのものを技術デモとして見せる

## 2. サイト構成(ページ一覧)

| パス | ページ | 概要 |
|---|---|---|
| `/` | メインページ | スクロール連動ストーリー型のランディング。各セクションにカードが登場し、クリックで詳細へ |
| `/works` | 作品一覧 | プロジェクトカードのグリッド |
| `/works/[slug]` | 作品詳細 | 1作品=1ページ。概要・技術・スクショ・リンク |
| `/about` | 自己紹介 | プロフィール・経歴・スキル詳細 |
| `/blog` | ブログ一覧 | 記事リスト(タグ・日付) |
| `/blog/[slug]` | ブログ記事 | Markdownで執筆 |
| `/contact` | お問い合わせ | フォーム+SNSリンク集 |

## 3. メインページの演出要件

- スクロール量に連動して要素が動き続ける「1本の映像」のような体験(GSAP ScrollTrigger の scrub を使用)
- 想定セクション構成:
  1. **Hero** — 名前・キャッチコピー。テキストや背景がスクロールで変形・退場
  2. **About導入** — プロフィール要素が流れ込み、カードクリックで `/about` へ
  3. **Works** — 作品カードが順に登場(ピン留め+横流れ等)。クリックで各 `/works/[slug]` へ
  4. **Blog** — 最新記事カード数枚。クリックで記事へ
  5. **Contact** — フッター兼コンタクト導線
- カードはホバー・フォーカスでも反応(キーボード操作可能に)
- `prefers-reduced-motion` 時はアニメーションを無効化し静的表示にフォールバック

## 4. 技術スタック

| 項目 | 採用 | 理由 |
|---|---|---|
| フレームワーク | **Astro** | 静的サイト+ブログに最適。Content Collectionsで記事・作品をMarkdown管理 |
| アニメーション | **GSAP + ScrollTrigger** | スクロール連動演出の業界標準。Lenis でスムーススクロール併用を検討 |
| スタイリング | Tailwind CSS | 速く書ける。デザイントークンを集約 |
| コンテンツ | Markdown (Content Collections) | blog / works を frontmatter 付き .md で管理 |
| ホスティング | Vercel または Cloudflare Pages | 無料枠・独自ドメイン対応 |
| フォーム | 外部サービス(Formspree 等)または mailto | サーバー不要で完結させる |

## 5. 非機能要件

- **パフォーマンス**: Lighthouse 90+ を目標。画像は最適化(Astro の Image)、アニメは transform/opacity のみで GPU 合成
- **レスポンシブ**: モバイル対応必須。モバイルでは演出を簡略化してよい
- **アクセシビリティ**: reduced-motion 対応、キーボード操作、コントラスト確保
- **SEO/OGP**: 各ページに meta / OGP 画像。ブログは RSS 配信
- **保守性**: 記事・作品の追加は .md ファイル追加のみで完結すること

## 6. スコープ外(v1ではやらない)

- CMS管理画面、コメント機能、多言語対応、ダークモード切替(検討事項)

## 7. マイルストーン案

1. セットアップ(Astro + Tailwind + GSAP)と全ページの骨組み
2. コンテンツモデル(works / blog のコレクション定義)と詳細ページ
3. メインページのスクロール演出実装
4. レスポンシブ・reduced-motion・SEO 仕上げ
5. デプロイ・独自ドメイン設定

## 8. 未決事項

- サイト名・独自ドメイン
- デザインの方向性(配色・フォント・トーン)
- 掲載する作品の初期ラインナップ
- お問い合わせフォームのサービス選定
